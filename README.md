## 🌟 Overview
A modern, glassmorphic, AI-powered and cloud-integrated full-stack developer portfolio showcasing Aditya Rajesh Chavan's technical background, education, internship, certifications, projects, coding profiles, and intelligent interactive AI tools.

### 🚀 Key Features
- **Frontend**: React (Vite) + Tailwind CSS + Framer Motion + Lucide Icons + Glassmorphism UI + Custom Glow Cursor + Particle Canvas.
- **Backend**: Node.js + Express.js (MVC Architecture) + MongoDB Mongoose + Nodemailer + JWT Auth + Rate Limiting.
- **AI Hub Features**:
  1. **AI Resume Chatbot**: RAG chatbot trained exclusively on Aditya's resume.
  2. **AI Project Explainer**: Generates system architecture, database design, features, challenges, and future scope.
  3. **AI Career Advisor**: Provides interview prep, technology roadmaps, and career advice.
  4. **AI Interview Simulator**: Interactive mock tech interview assistant (.NET, C#, SQL Server, DSA, Backend, HR).
  5. **AI Resume Analyzer**: Upload/paste visitor resume to score ATS match against Aditya's tech profile.
  6. **AI Code Generator**: Instantly generates ASP.NET Controllers, C# CRUD APIs, Node.js endpoints, and SQL queries.
- **Cloud & Admin**: Live visitor counter, resume download tracking, contact form storage in MongoDB, Nodemailer alerts, Admin Dashboard.

## ⚙️ Quick Start

### 1. Backend Setup
```bash
cd server
npm install
npm run seed     # Seeds projects, skills, and admin account
npm start        # Starts server on http://localhost:5000
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev      # Starts Vite dev server on http://localhost:5173
```
